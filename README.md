# Discord Chat Exporter

A modern, dark-themed GUI application that lets you export messages from any Discord channel (that you have access to) into **HTML**, **TXT**, or **CSV** files.

---

## Features

- **Multiple export formats** – HTML (styled chat view), plain TXT, or CSV
- **Optional token caching** – save your Discord token locally so you don’t have to re-enter it
- **Rate-limit respect** – automatic retries when Discord throttles requests
- **Threaded fetching** – GUI stays responsive while downloading

---

## Installation

### Prerequisites
- **Python 3.0 or newer**
- **pip** (comes with Python)
